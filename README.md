# LOOP

The launchpad of confidential tokens on Solana. Privacy moves in circles.

LOOP is a Solana token launchpad built around Privacy Rings. Every token launched on LOOP supports confidential balances and private transfers, while still trading across the wider Solana ecosystem.

X: https://x.com/LoopLaunchFun

## Files

- `index.html` is the whole site in one file. Styles, scripts and the logo are built in.
- `logo.png` is the LOOP ring logo.

## Run locally

Open `index.html` in a browser. No build step is needed.

## Deploy with GitHub Pages

1. Push these files to the root of the repository.
2. In the repository, open Settings, then Pages.
3. Under Build and deployment, choose "Deploy from a branch", pick `main` and `/ (root)`, and save.
